    
    Este proyecto es una tienda online de zapatillas, desarrollada con React. 
    Incluye un catálogo de productos, detalle individual, carrito de compras.

    🚀 Tecnologías utilizadas

        🔹React (Vite)
        🔹React Router para navegación
        🔹Context API para el manejo del carrito
        🔹CSS / Bootstrap
        🔹React Icons
        🔹Fetch para obtener productos
        🔹MockApi
        🔹Netifly
    
    📦 Funcionalidades

        ✔️ Listado de zapatillas
        ✔️ Página de detalle del producto
        ✔️ Carrito de compras
        ✔️ Paginador
        ✔️ Agregar / eliminar / editar productos
        ✔️ Cálculo automático del total
        ✔️ Login (Administrador)
        ✔️ Ruteo SPA
        ✔️ Diseño responsive
